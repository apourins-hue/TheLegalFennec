# The Legal Fennec

An independent publication on law, technology and society.

## Publishing

GitHub Pages source: `main` branch, `/ (root)`. `index.html` is the homepage.

First article: `articles/you-created-it-but-do-you-own-it.html`.

To publish an update, upload or edit the relevant HTML file and commit the change.

## Contact page
`contact.html` provides public topic suggestions through GitHub Issues. To offer private enquiries, later connect a dedicated editorial email or compliant form service; do not add a private personal email to public HTML.
